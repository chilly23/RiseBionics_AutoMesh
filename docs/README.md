# Diagram sources

`architecture.png` is the README figure. `architecture.svg` provides a vector export.
`architecture.html` is the editable light source. Dark and full editorial HTML variants are included.

The figure uses Diagram Design's light paper, orange focal accent, orthogonal connectors and editorial type hierarchy.
ManimGX's geometry examples informed the component illustrations: projected mesh grids, circuit primitives and circular curves.
These are static HTML/SVG figures, not ManimGX animation renders.

The 1280 × 720 composition uses the presentation type scale. PNG exports use twice that resolution.
Instrument Serif, Geist and Geist Mono are requested from Google Fonts; Georgia, Arial and Consolas are the offline fallbacks.

Solid arrows show connections or handoffs. Dashed arrows show returned responses or measurements where present.
Illustrations identify component roles. They are not hardware drawings, runtime captures or measured results.
