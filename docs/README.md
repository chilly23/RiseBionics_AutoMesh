# Diagram sources

`architecture.html` is the editable light source. `architecture-dark.html` and `architecture-full.html` provide alternate views.
`architecture.png` is the README image. `architecture.svg` provides an editable vector export.

The diagrams follow the supplied Diagram Design reference with its default light and orange palette.
The HTML requests Instrument Serif, Geist, and Geist Mono. Georgia, Arial, and Consolas provide fallbacks when webfonts are unavailable.

Connections describe the checked-in implementation or documented hardware. They do not certify runtime behavior or hardware validation.
